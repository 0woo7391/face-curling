# FACE CURLING — 화면 구조와 UI 규칙 (v0.1)

- 상태: **적용됨** (커밋 기준). 이후 화면을 추가·변경할 때 이 문서의 규칙을 지킨다.
- 기준: 세로 화면 하나 [확정], 방향 A(스티커 + 장난감 링크) [확정], 정답 안내 표시 없음 [확정], 명세 v1.2 3장.
- 참고 요청된 외부 가이드(lucianlabs.dev/uxui-prompt)는 세션 네트워크 정책으로 열지 못해 반영하지 않았다. 허용되면 이 문서를 그 기준과 다시 대조한다.

## 1. 점검 결과 (적용 전 → 조치)

| # | 문제 | 왜 문제인가 | 조치 |
|---|---|---|---|
| 1 | 시작 화면 없음 | 무슨 게임이고 무엇부터 하는지 알 수 없음 (명세 3.1 홈 미구현) | **홈 화면** 추가 |
| 2 | 상단바 7개 버튼이 같은 무게 | 플레이 조작과 설정·개발 도구가 섞여 시선 분산 | 상단은 **⏸ + 진행 칸**만. 나머지는 홈·일시정지로 |
| 3 | 재시작이 확인 없이 실행 | 진행 중 게임이 한 번에 사라짐 | 일시정지 안으로 옮기고 **두 번 눌러 확인** |
| 4 | 기록/연습이 플레이 중 드롭다운 | 시작 전에 고를 선택인데 중간에 바뀜, 의미가 안 보임 | 홈에서 **시작 / 연습** 버튼으로 |
| 5 | 얼굴 만들기가 📷 아이콘 하나 | 게임의 핵심 기능이 숨겨짐 | 홈의 **얼굴 카드**. 사진 얼굴이 없으면 노란 테두리로 강조 |
| 6 | 일시정지·나가기 없음 | 멈추거나 그만둘 방법이 없음 | **⏸ 일시정지 시트**: 계속 / 처음부터 / 홈 / 소리 / 조작법 / 튜닝 |
| 7 | 진행 상황이 글자("기록 · 2/6") | 한눈에 안 들어옴 | **6개 부위 칸**: 미투구 흐림, 현재 흰 테두리, 던진 뒤 점수와 색, 번드·이탈은 빨간 ✕ |
| 8 | 결과 뒤 행동이 "다시 하기"뿐 | 다음 행동이 막힘 | **다시 하기(주) / 홈**, 연습 모드는 **마지막 투구 다시** |
| 9 | 상단 버튼 38px | 터치 권장 최소 44px 미만 | ⏸ 44px, 홈 하단 버튼 44px |
| 10 | 일시정지 시트가 아래 조작부와 겹침 | 어느 버튼이 살아 있는지 헷갈림 | 일시정지 중에는 아래 조작부를 숨김 |
| 11 | 사진 얼굴의 부위 버튼이 색 점뿐 | 어떤 부위인지 그림으로 안 보임 | 부위 버튼·진행 칸에 **실제 부위 스티커** |

## 2. 화면 흐름

```text
[홈] ──시작──▶ [게임: 부위 선택 → 당기기(방향·파워) → 스위핑 → 정지] ×6 ──▶ [결과]
 │  └─연습──▶ (같은 게임, 번드 시 재투구·되돌리기 가능)                         │
 ├─📷 만들기/바꾸기 ─▶ [얼굴 만들기: 사진 → 자르기 → 다듬기 → 빈 얼굴] ─▶ [홈]   │
 └─조작법 (도움말 시트)                                                         │
[게임] ──⏸──▶ [일시정지] ─계속─▶ [게임]                                         │
                 ├─처음부터(진행 중이면 두 번) ─▶ [게임 처음]                    │
                 └─홈으로(진행 중이면 두 번) ───▶ [홈]                          │
[결과] ──다시 하기──▶ [게임 처음]   ──홈──▶ [홈]   ──(연습) 마지막 투구 다시──▶ [게임]
```

- 앱 화면 상태는 `app.screen = 'home' | 'game'`, `app.paused`. 게임 내부 상태(명세 8장)와 분리한다.
- 홈·일시정지에서는 물리 틱이 멈추고, 마우스 잠금·스위핑 입력을 받지 않는다.
- 데스크톱: `Esc`(마우스 잠금이 없을 때) 또는 `P`로 일시정지.

## 3. 화면 배치 규칙

모든 화면은 세로 한 장을 **위 / 가운데 / 아래** 세 띠로 나눈다.

| 띠 | 역할 | 들어가는 것 |
|---|---|---|
| 위 | 상태 | 게임: ⏸, 부위 진행 칸, 연습 배지 · 홈: 로고 · 오른쪽 위: 보드 미니맵(투구·스위핑 중) |
| 가운데 | **게임 화면 (항상 비워 둠)** | 3D 장면만. 카메라는 HUD가 차지하지 않은 영역 가운데에 장면을 놓는다 |
| 아래 | 행동 | 단계 칩 → 힌트 한 줄 → 버튼, 또는 부위 선택 3×2, 결과·일시정지·홈 시트, 터치 문지르기 판 |

규칙:

1. **화면마다 주 행동은 하나**: 흰색 큰 버튼(`.primary`) 하나만. 나머지는 어두운 버튼.
2. **가운데 띠에는 HUD를 두지 않는다.** 예외는 화면 밖 캐릭터 표시와 번드 도장(잠깐).
3. **되돌릴 수 없는 행동은 두 번 눌러 확인** (진행 중일 때만). 버튼이 빨갛게 바뀌고 2.5초 뒤 원래대로.
4. **터치 대상 최소 44px**.
5. **글자는 한 줄 힌트까지만.** 상태는 색·크기·모양으로 (진행 칸, 빗자루 색, 고리, 막대).
6. **정답 위치 안내 금지**: 예상 경로, 멈출 곳, 빗자루 자리 가이드, 정답 유령 표시는 디버그 전용.
7. **겹침 금지**: `tools/check-overlap.cjs`가 화면 4종 × 8단계(홈·부위 선택·방향·회전·파워·스위핑·일시정지·결과)에서 HUD끼리, HUD와 스톤·캐릭터·얼굴의 겹침을 검사한다. 화면을 바꾸면 반드시 돌린다.
8. **층 순서**: 게임 장면 < HUD < 시트(결과·일시정지·홈 패널) < 얼굴 만들기 < 도움말. 시트가 열리면 그 아래 조작부는 숨긴다.

## 4. 화면별 구성

### 홈
- 위: 스티커 로고. 가운데: 현재 얼굴 보드(카메라가 로고와 패널 사이에 맞춤).
- 아래 패널: **얼굴 카드**(썸네일 · 이름 · 설명 · 만들기/바꾸기) → **시작**(주) → 연습 · 조작법 → 소리. 튜닝(⚙)은 주소에 `?debug`가 있을 때만. 연습 버튼 아래 "실수 되돌리기".
- 첫 실행(사진 얼굴 없음): 얼굴 카드에 노란 테두리, 버튼이 흰색 "📷 만들기". 기본 얼굴로 바로 시작도 가능.

### 게임
- 위: ⏸(44px) · 진행 칸 6개 · (연습이면) 연습 배지.
- 위: 진행 칸 6개에 부위 그림(사진 = 스티커, 기본 = 도형). 결과 화면에서는 숨김(아래 점수 막대와 중복).
- 아래: 부위 선택 3×2(부위 그림 + 이름) / 던지기: 힌트 + ◀ 부위 변경 (당기는 중에는 숨김) / 스위핑: 왼쪽·곧게·오른쪽 세 칸 판, 지금 흔드는 칸이 밝아짐.
- 처음 한 번만 손가락 애니메이션: 첫 투구 전 아래로 당기기, 첫 스위핑에서 좌우로 흔들기.
- 던진 스톤이 멈추면 그 자리에 점수가 떠오른다.

### 던지기 (v0.2)
- **새총 한 번**: 화면 아무 데나 누른 채 아래로 당기면, 당긴 반대 방향이 투구 방향(±12°), 당긴 길이가 파워(화면 높이의 32% = 100%). 놓으면 발사, 위로 올리면 취소.
- 당기는 동안: 스톤이 뒤로 당겨지고, 화살표가 길어지며, 옆 막대가 차오른다(초록→빨강).

### 스위핑 (v0.2)
- **자동 따라가기(기본, 쉬움)**: 캐릭터가 스톤 앞에 알아서 붙는다. 플레이어는 **누른 채 좌우로 흔들기만** — 폰은 화면 어디서든 손가락 하나로 좌우 문지르기, PC는 마우스 버튼을 누른 채 좌우로. 방향이 바뀔 때마다 한 번 쓸기(첫 방향은 자유), 빗자루는 손의 좌우 위치를 따라 스톤 앞에서 움직인다. 아래 ◀▶ 표시가 다음 방향을 알려 준다. 마우스 잠금 없음. 위치를 플레이어가 잡지 않으므로 번드 판정 없음.
- 실력 요소: 얼마나 빨리 꾸준히 문지르는지(초당 약 5번이면 최대), **언제 쓸고 언제 멈출지**(쓸면 덜 휘고 조금 더 감), **어디서 흔들지**(화면 왼쪽/오른쪽에서 흔들면 그쪽으로 끌림, 빗자루도 스톤 앞 그쪽으로 비켜남). 스톤 앞 초록 화살표: 방향 = 끌리는 쪽, 길이·색 = 스위핑 세기 (스톤 둘레 강도 고리는 없앰).
- 굴러가는 동안 스톤 옆 **속도 막대**(빠름 = 길고 초록, 느림 = 짧고 빨강). 발사 전에는 겨냥 방향 **일직선**(레인 끝까지, 휘는 길·멈출 곳은 그리지 않음).
- **직접 이동(어려움)**: 개발용. 튜닝 패널에서만 켜고, 저장값은 무시해 항상 자동으로 시작한다.

### 일시정지 (하단 시트)
- 계속하기(주) / 처음부터 다시 / 홈으로 / 소리 · 조작법 · 튜닝.

### 결과 (하단 시트)
- 큰 점수 → 부위별 막대 → 다시 하기(주) · 홈 · (연습) 마지막 투구 다시. 위쪽은 실제 크기 스티커가 붙은 얼굴.

### 얼굴 만들기
- 위: ✕ + 4단계 칩. 가운데: 1:1 캔버스. 아래: 단계별 도구 → 이전 / 다음(주).
